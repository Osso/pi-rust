# Node temporary directories

`pi_js_compat::node_fs::mkdtemp` is the shared private-directory authority. The spool uses the same authority that later Node filesystem consumers can call. [Spool proof](../porting/traceability/session-transcript-spool.md).

## What it must do

- [x] Append six random ASCII alphanumeric characters to the exact prefix and create exclusively with POSIX mode0700.
- [x] Reject NUL prefixes with Node's exact TypeError/ERR_INVALID_ARG_VALUE.
- [x] Return filesystem errors as NativeNodeError with exact message/code/errno, syscall `mkdtemp`, and the unexpanded `prefix + XXXXXX` error path.

## Out of scope

Random suffix bytes are nondeterministic; proof compares the source alphabet/length, not generated bytes. libc's random generator/collision exhaustion and warning behavior are native runtime oddities under the approved policy; native creation bounds collisions at256. Windows behavior retains the existing platform gap.

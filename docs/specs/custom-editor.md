# Custom editor

Frozen authority: `packages/coding-agent/src/modes/interactive/components/custom-editor.ts` at the [common pin](../porting/source-lock.json).

- Preserve the inherited Editor text, rendering, focus, autocomplete, working-prompt and history surfaces; application actions must not preempt extension shortcuts or active-autocomplete Escape cancellation.
- Dispatch in frozen order: extension shortcut; paste image (consumes even without a callback); interrupt (dynamic escape preferred); exit only when empty (dynamic Ctrl+D preferred); remaining matching actions in insertion order; base Editor. Only a remaining-action result equivalent to literal `false` continues dispatch. Interrupt/exit ignore their registered handler's return value.
- Callbacks may re-enter the mounted editor. A continuation observes their completed text mutations before checking subsequent conditions or invoking the base Editor. Native subclass adapters preserve this ordering.
- A false/absent control DB path disables history migration/persistence. Otherwise import legacy JSON strings, cap at 100 before the optional filter, and delegate trimming/history rules to Editor. Missing/unreadable/malformed/non-array legacy files yield empty legacy history. Preserve Node UTF-8 decoding at file I/O.
- Persist the newest history entry only when inherited history changed. The non-persistent method changes memory only. Persistence failures retain the inherited memory mutation and propagate; a duplicate retry with unchanged memory does not retry persistence.
- SQLite boundaries match frozen bytes. Direct string bindings use the shared Node UTF-8 projection; JSON-driven legacy migration retains its frozen SQL path. Reads use the shared Node SQLite `JsString` decoder, including invalid UTF-8 generated by SQLite JSON extraction.
- `EditorComponent::add_to_history` returns a typed native error. Native callers bubble it at frozen uncaught boundaries. Selected-agent steering catches it, reports the error and restores submitted text, without clearing the editor as if history succeeded.

Proof and Rust representation: [traceability](../porting/traceability/interactive-custom-editor.md).

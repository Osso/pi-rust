## Discrepancies and approved exclusions

- **DISCREPANCY — preserved callback failures:** stdout/stderr stream read errors have no frozen handler and remain uncaught. Null JSON events throw in the line listener. Truthy wrong-type paths and defined wrong-type inline text throw in the close callback. A relative path after cwd deletion also throws there. Frozen's outer tool promise remains unsettled for close-callback rejection; native preserves that uncaught boundary through `throw_native_uncaught`, never ToolError or a generic panic payload. Default exit1 and native error identity are process-proven. Falsy paths still count without producing rows; positive context ignores inline text; a nonzero child exit wins before formatting.
- **Approved runtime gaps:** native stream chunk partitioning and Node readline's elapsed CRLF window are not emulated. Shared Node/Windows runtime behavior is limited to the approved POSIX/native policy; no new timer/capture compatibility path. V8 stack text remains omitted under the standing error policy.
- **Approved representation policy:** returned values/cache content are owned; source object-identity mutation is not reproduced. Built-in Text component reuse is relied on by the consumer and is preserved. Invalid JavaScript core-API input types are excluded; all valid binary64 options, arbitrary human text and external process JSON remain in scope.
